# Print Checklist

Use this checklist before printing real labels or sale-day sheets.

## Cross-Reference Labels

1. Add or filter the catalog items you want to print.
2. Click **Labels** to load the current filtered list into the label queue.
3. Choose the sheet preset:
   - **Compact tags** for general storage bins and hang tags.
   - **Avery 5160** for 30-up address-label sheets.
   - **Large tags** for bigger sale or storage labels.
4. Print one plain-paper test page first.
5. In the browser print dialog, use:
   - Scale: `100%`
   - Margins: `None` or the printer's minimum margin option
   - Headers and footers: off
   - Background graphics: on, if the browser exposes that option
6. Scan one QR code with a phone camera and one barcode with a barcode app before using label stock.
7. Hold the test page behind the real label sheet and check alignment against the label edges.

## Yard-Sale Sheets And Tags

1. Mark sale candidates as **Sell**, **Unsure**, **Donated**, or **Sold**.
2. Add asking price and private floor price before printing.
3. Print **Sale Sheet** for private tracking.
4. Print **Price Tags** for public sale-day tags.
5. Keep the private sale sheet off the public table because it includes floor prices and notes.

## Troubleshooting

- If labels drift down the page, make sure browser scaling is `100%`.
- If labels are clipped, use the printer's minimum margin setting or the compact preset.
- If QR codes scan but open an old page, refresh the app once so the newest service worker is active.
- If printed barcodes are hard to scan, try the large-tag preset or increase print quality.
